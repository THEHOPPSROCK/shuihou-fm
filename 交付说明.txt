水喉FM · 88.8 街坊频道 —— 交付说明 v1.0（2026-11-17）
=========================================================

一、这是什么
  水喉FM 是东莞水务环境集团旗下文创品牌「大水喉」家族出品的 AI 街坊电台，
  「大水喉」任唯一主播兼品牌官方发言人。本包为可直接部署的手机优先静态站。

二、怎么运行
  方式 A（推荐，一键）：双击 serve.cmd，浏览器会自动打开 http://127.0.0.1:8811
  方式 B：在本目录执行  python -m http.server 8811
  方式 C：把整个文件夹上传到任意静态托管（Nginx / OSS / CDN / GitHub Pages 均可）

  注意：页面使用 ES module，必须经 HTTP 打开，直接双击 index.html 会被浏览器拦截。

三、手机预览
  1) 手机与电脑连同一个 Wi-Fi；
  2) 电脑防火墙放行 8811 端口；
  3) 用 http.server 启动时加 --bind 0.0.0.0，手机访问 http://<电脑内网 IP>:8811

四、两种播出模式（右上角 ⚙ 设置切换）
  · 录播 DEMO（默认）：本地剧本，不发任何真实请求，适合演示与评审。
  · 真实频道：填入自己的 DeepSeek API Key 后直连 api.deepseek.com，
    联网搜索、深度思考、文件解析、粤语朗读、语音输入、会话标题、安全播出全部接通。
    Key 只存浏览器 localStorage，不上传第三方；正式对外服务建议加服务端代理。

五、功能清单
  · 对话：录播剧本 / 真实流式对话、思考与检索默认折叠、引用角标、参考来源、追问建议
  · 工具：联网、深度思考、上传文件、语音输入、朗读、清空
  · 转人工：输入框红色按钮 → 底部快捷拨号面板（客服热线 0769-96968，tel: 唤起电话 App）
  · 收纳目录：左上 ☰ 抽屉（今日节目表 + 饮水打卡），选节目自动收起并开问
  · 大水喉动画：空态贴图可点，播 9:16 品牌动画（12 秒、只播一次）→ 反馈「今日你饮水未？」
  · 导入历史：⚙ 设置 →「选择 DeepSeek 导出文件…」，本机解析 JSON，铺回聊天窗
  · 声线试镜：voice.html（入口在 ⚙ 设置），两条入围粤语声线 + 盲测

七、已知边界
  · 录播模式下的停水时间、来源与数字均为演示内容，不代表真实查询结果。
  · 真实频道需用户自备 DeepSeek API Key；浏览器直连适合演示，正式产品请走服务端代理。
  · 动画视频 4.4MB，正式投放前建议压到 1–1.5MB。
  · 浏览器兼容：Chrome / Edge / Safari 最新版；需要支持 ES module、dvh、aspect-ratio。
